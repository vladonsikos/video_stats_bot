# Video Stats Telegram Bot

Telegram-бот для аналитики видео на основе естественного языка.  
Использует OpenRouter (бесплатные LLM) для преобразования вопросов в SQL и PostgreSQL для хранения данных.

## Архитектура

- **PostgreSQL** – две таблицы: `videos` (итоговая статистика) и `video_snapshots` (почасовые срезы).
- **Загрузка данных** – скрипт `load_data.py` читает `videos.json` и заполняет БД.
- **Telegram Bot** – aiogram 3.x, асинхронный.
- **LLM** – через OpenRouter (модель `mistralai/mistral-7b-instruct`). Промпт содержит описание схемы и примеры, чтобы модель генерировала корректный SQL.
- **Логика ответа**: вопрос → LLM → SQL → выполнение запроса → число → ответ пользователю.

## Запуск через Docker

1. Клонируйте репозиторий (или создайте файлы вручную).
2. Положите `videos.json` в корневую папку.
3. Создайте файл `.env` на основе `.env.example` и укажите токены:
TELEGRAM_BOT_TOKEN=ваш_токен
OPENROUTER_API_KEY=ваш_ключ
DATABASE_URL=postgresql://postgres:postgres@postgres:5432/video_stats
4. Выполните:
```bash
docker-compose up --build```
5. Бот запустится, загрузит данные и начнёт отвечать на сообщения.
Использование:
Напишите боту вопрос на русском языке, например:

"Сколько всего видео?"

"Сколько видео у креатора aca1061a9d324ecf8c3fa2bb32d7be63 с 1 по 5 ноября 2025?"

"На сколько просмотров выросли все видео 28 ноября 2025?"

Бот ответит одним числом.

Примечания:
Для дат используйте формат "28 ноября 2025" – модель преобразует его в '2025-11-28'.

Все запросы выполняются в рамках одной транзакции, результат – всегда одно число.

В случае ошибки бот отвечает "0" или сообщением об ошибке.

Файл videos.json не должен попадать в репозиторий (добавлен в .gitignore).
